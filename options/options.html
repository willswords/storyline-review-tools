Side panel sections

Review sites

The extension always works on Articulate Review. It can also work on courses shared for review on these sites. Chrome asks you to allow each one when you turn it on.

Review sites

Sites

The extension works on Storyline courses on Articulate Review. Add other sites that serve Storyline courses, such as your LMS, to use it there too. Chrome asks you to allow each site.

  • https://articulateusercontent.com/review/*Articulate Review, always on
A web address, where * matches anything: for example https://burnsmcd.csod.com/* for a whole site, or https://lms.example.com/content/* for one part of it. A bare name such as lms.example.com becomes https://lms.example.com/*.

After adding a site, reload any course already open on it. The extension’s options (Unlock all navigation and so on) apply on every site it works on. Removing a site also takes away the extension’s access to it.
